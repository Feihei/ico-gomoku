# 你会玩个球五子棋（球面五子棋）

把传统五子棋从平面棋盘搬到**球面**上：棋盘是正二十面体细分生成的球形三角网格，棋子落在网格顶点上，任意一方沿网格边连成 5 子一线即获胜。有限、无边界、可循环——消除平面棋盘的边角效应，降低和棋率。

## 玩法

- 黑先白后，轮流在空顶点落子；连成 **5 子一线**（近似直线）即胜
- 棋盘上 12 个带小墨点的位置是**星位点**（五价点）：可以落子，连珠方向按实际邻接处理
- 鼠标拖拽旋转视角、滚轮缩放；胜负后中央弹出大字（黑胜/白胜/和棋）

## 运行

静态页面，无构建、无框架。起任意静态服务器打开即可：

```bash
python -m http.server 8000
# 浏览器访问 http://localhost:8000
```

> three.js 经 jsdelivr CDN 引入，运行需联网。

详细的设计决策与开发约定见 [AGENTS.md](./AGENTS.md)。

# ico-gomoku (Spherical Gomoku)

Gomoku moved from a flat board onto a **sphere**: the board is a spherical triangular mesh generated by subdividing an icosahedron. Stones are placed on mesh vertices, and the first player to line up **5 stones** along mesh edges wins. The board is finite yet unbounded — play wraps around the sphere, removing corner effects and lowering the draw rate.

## How to Play

- Black moves first, then players alternate placing stones on empty vertices; **5 in a row** (nearly straight along the mesh) wins
- The 12 vertices marked with small ink dots are **star points** (degree-5 vertices): you may play on them, and line directions follow the actual adjacency
- Drag to rotate the view, scroll to zoom; the result appears as large text in the center of the screen (黑胜 / 白胜 / 和棋 — "Black wins" / "White wins" / "Draw")

## Run

A static page with no build step and no framework. Serve it with any static server and open it:

```bash
python -m http.server 8000
# open http://localhost:8000
```

> three.js is loaded from the jsdelivr CDN, so an internet connection is required.

For design decisions and development conventions, see [AGENTS.md](./AGENTS.md).
